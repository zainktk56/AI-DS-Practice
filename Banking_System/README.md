# 🏦 Streamlit Banking System

A simple, secure **Core Banking Application** built using **Python 3.14** and **Streamlit**. This project transitions standard terminal-based banking workflows into a modern, responsive web application interface.

### ✨ Features
* 👤 **Account Management:** Instantly open accounts with randomly generated account numbers and secure authorization PINs.
* 💰 **Core Banking Operations:** Smooth real-time deposits, balance inquiries, and withdrawal safety limits.
* 🔄 **Peer-to-Peer Transfers:** Secure intra-bank fund routing with absolute validation checks against duplicate or self-transfers.
* ❌ **Account Closure Safety:** Safe account deletion system that reads, secures, and outputs outstanding balances before erasing user database paths.
* ⚙️ **State Persistence:** Implements Streamlit `session_state` structural tracking mechanisms to prevent memory losses across web layout updates.
